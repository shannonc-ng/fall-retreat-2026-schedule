# Novus Global Fall Retreat 2026 Schedule

Password-protected retreat schedule with breakout sign-ups. Runs on Bun and deploys to the `retreat-schedule` service in the "Fall Retreat 2026 Schedule" Railway project on every push to `main`.

Variables (set in Railway): `SITE_PASSWORD`, `DATABASE_URL`.

Local run: `DEV_MEMORY=1 SITE_PASSWORD=test bun index.tsx`
